# Hardware

No serial number, hardware UUID, MAC address, public address, credential, or
private key is recorded here.

## Agar — runtime substrate

- Local name: `agar-MacBook-Pro`
- Model: MacBook Pro (`MacBookPro12,1`)
- Processor: 2.7 GHz dual-core Intel Core i5
- Memory: 8 GB
- Operating system: macOS Monterey 12.7.6 (21H1320)
- Network role: local LAN only
- Runtime architecture: x86_64

Agar holds the continuing Rill process, Rill World, the two mapped state files,
and the physical camera, microphone, Bluetooth radio, display, battery, and
thermal environment.

## Mac Studio — development and archival surface

- Model: Mac Studio (`Mac17,14`)
- Chip: Apple M5 Max, 18 CPU cores
- Memory: 36 GB
- Operating system at repository creation: macOS 27.0.1 (26A434)

The Studio cross-compiles the x86_64 binaries, holds source and repository
history, and connects to Agar over the authenticated local LAN path.
