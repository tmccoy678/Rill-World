# Experiment 02 plan: effective Level 0 to Level 1

Status: planning only. No source, executable, build target, deployment path, or
root trial exists.

## Question

Can bounded local material-like state form a persistent surrounding geometry
that changes transfer through a narrow path, without initializing any site as a
gate or assigning a higher-level function?

## Conceptual primitive

The trial begins with the effective Level 0 site representation specified in
`EQUATIONS.md`: two conserved unnamed contents, finite unoccupied capacity,
local potentials, local cohesion, local competition, bounded fluctuation, and
conservative nearest-neighbor transfer. Permeability exists as a present local
relation among those quantities.

## Required emergence

The trial may claim a Level 1 result only if:

1. the controlling geometry arises from local Level 0 relations;
2. transfer changes because of that geometry;
3. the controlling state surrounds or bounds the path rather than becoming the
   transferred state;
4. the relation persists for more than one local update;
5. removal of supporting local conditions allows change or dissolution;
6. no semantic gate state exists in initialization or update code.

## Implementation surface

The proposed implementation surface is a cache-aligned array of local sites.
This accessible representation layer carries the effective Level 0 physics.

No four-stream or root execution is approved by this plan. The number of
threads, ordering rule, hardware observation, and one-time run boundary remain
unresolved until the local equations pass review.

## Comparative scope

The trial includes only local transfer and the possible emergence of a
surrounding permeability relation.

It deliberately postpones:

- long-range pushed or pulled flow;
- source–sink transport;
- moving-structure-generated streaming;
- self-propagating coupled waves;
- direct branch delivery;
- passage growth, branching, sealing, and reopening;
- network remodeling through transfer;
- damage isolation and proportional repair;
- repeated regional coordination;
- host-condition coupling;
- higher-level carriers and templating.

The initial representation must preserve room for these later possibilities.

## Preservation boundary

`DEVELOPMENTAL-SYNTHESIS.md` defines the larger architecture of which this
trial is one projection. Its representation must remain extensible to:

- locally acquired orientation;
- additional physical interaction classes;
- conditional local bonds;
- ordered connected strands;
- transfer that changes structure and structure that redirects later
  transfer;
- nested mapping onto Agar's real hardware locality.

These are preservation requirements for the lineage; the first trial is judged
by its stated Level 0 to Level 1 bridge.

## Explicit exclusions

- no carrier;
- no fixed passage wall;
- no strand or copying;
- no external environmental input;
- no hardware device input;
- no persistence;
- no live runtime connection;
- no semantic runtime log;
- no root launch.

## Required next decision

Review `EQUATIONS.md` as the candidate's effective Level 0 physics. Code begins
after its conserved quantities, local asymmetry, transfer law, and claim
boundary are accepted on their mechanics.
